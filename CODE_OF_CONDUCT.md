# Code of Conduct

This project is intended to be a practical, respectful place to collaborate.

## Expected behavior

- Be direct and constructive.
- Assume good intent while still asking for clarity when something is unclear.
- Keep criticism focused on code, design, documentation, and project impact.
- Respect maintainers' time by keeping reports and pull requests reproducible.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Personal attacks or repeated bad-faith arguments.
- Publishing private information without consent.
- Spam or unrelated promotion.

## Enforcement

Maintainers may edit, hide, or remove comments and may block contributors who
act against this code of conduct. Serious safety or abuse reports should be sent
privately when the project has a private contact or security advisory channel.
